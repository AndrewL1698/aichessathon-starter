# nnue h256-100m-e11 — `weights/nnue-h256-100m-e11.npz` (interim, absolute target)

The first export from the 163M-unique-position run, shipped early because the M5 spent most
of the afternoon asleep on battery and the run is at epoch 11 after three hours of wall time.
Absolute target (`target = "cp"`), for the v4.0 blend `leaf = (hand + net) / 2`. Pipeline commit
582dd78.

## Data

Union of two slices of `lichess_db_eval.jsonl.zst`, same filters and `--mirror` as before:

| slice | bytes | records read | skipped | unique | mirrors | rows |
|---|---|---|---|---|---|---|
| 1 (`lichess-48m`) | 0 – 7.5e9 | 56,952,380 | 5,264,600 | 51,687,780 | 38,312,220 | 90,000,000 (cap) |
| 2 (`lichess-slice2`) | 7.5e9 – 15e9 | 123,501,675 | 12,087,825 | 111,413,850 | 88,586,150 | 200,000,000 (cap) |
| union (`lichess-100m`) | | | | **163,101,630** | | **290,000,000** |

Slice 2 starts at the first zstd frame boundary after byte 7.5e9 and skips its cut first
line (f4e2ee7). The two slices were ingested separately and unioned by symlink; the ingester is
deterministic per record, so this equals one pass over the 15 GB prefix. **RAM:** 19,140 MB of
index rows plus 1.7 GB of labels and targets, loaded with the preallocating loader (582dd78);
the old concatenating loader would have peaked near 38 GB.

## Training

`768 → 256 → 32 → 1`, Adam lr 1e-3, batch 16384, `--l1-clip 1.9` (exports at qa=512 by
construction), `--patience 10 --min-delta 1e-5`, 2% split = 5,800,000 rows. 100 s per epoch when
the machine is awake; 144 to 366 s as logged, because of sleep.

| epoch | train | val |
|---|---|---|
| 1 | 0.016809 | 0.015733 |
| 5 | 0.014785 | 0.014734 |
| 10 | 0.014401 | 0.014409 |
| 11 | 0.014361 | **0.014383** |

Mean predictor on this split 0.055424. For scale, the shipped net (h256-52m-e60) reached
0.014602 at epoch 60 on the 90M split and the 120-epoch run 0.014449; this run is below both
after 11 epochs on a split drawn from a superset of that data. Still falling ~3e-5 per epoch.
The run continues; a later epoch replaces this file under the final name.

## Export

qa=512, qb=1024, qc=128, cp_scale=400, target=cp: headroom 1,450; 292,187 bytes.

- `test_export`: **3.02 cp mean, 9.53 cp p99, 14.31 cp max** (tolerance 5 / 25); re-encode
  exact 1000/1000; mirror invariance 1000/1000. OK. Twice the layer-1 precision of the shipped
  file (qa=256).

## Commands

```bash
uv run python -m tools.nnue.data lichess --input data/nnue/lichess_slice2_aligned.zst \
  --positions 200000000 --out tools/nnue/data/lichess-slice2 --mirror
# union: symlink lichess-48m/*.npz as a_* and lichess-slice2/*.npz as b_* into lichess-100m/
uv run python -m tools.nnue.train --data tools/nnue/data/lichess-100m --epochs 100 --hidden 256 \
  --l1-clip 1.9 --patience 10 --min-delta 1e-5 --checkpoints tools/nnue/checkpoints-h256-100m
uv run python -m tools.nnue.export --checkpoint tools/nnue/checkpoints-h256-100m/epoch_011.pt \
  --out weights/nnue-h256-100m-e11.npz --qa 512 --qb 1024
uv run python -m tools.nnue.test_export --weights weights/nnue-h256-100m-e11.npz \
  --checkpoint tools/nnue/checkpoints-h256-100m/epoch_011.pt
```
