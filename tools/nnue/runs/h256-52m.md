# nnue h256-52m — `weights/nnue-h256-52m.npz`

The [h256](h256.md) configuration on 2.5x the data. Pipeline commit c800a07.

## Data

The first **7,500,000,000 bytes** of `lichess_db_eval.jsonl.zst` (the v1 prefix plus the next
3 GB, fetched the same way: 40 chunks of 187.5 MB, 6 at a time). One ingest pass with the same
filters: **56,952,380 records read, 5,264,600 skipped**, giving **51,687,780 unique positions**
plus **38,312,220 a-h mirrors** = **90,000,000 rows** (the `--positions` cap; the prefix was not
exhausted) in 180 shards, 1.4 GB. Sign check +0.512 / +0.407, identical to v1 since the first
2000 records are the same. This is a superset of v1's data; v1's 36M rows are the first 72
shards, so v1 and this run are not on the same validation rows.

## Training

`768 → 256 → 32 → 1`, Adam lr 1e-3, batch 16384, 30 epochs, 2% split (1,800,000 rows), seed 1.
**19.1 s per epoch**, 9.6 min. 5.9 GB of index rows resident.

| epoch | train | val |
|---|---|---|
| 1 | 0.018922 | 0.017231 |
| 10 | 0.015227 | 0.015397 |
| 20 | 0.014881 | 0.015064 |
| 25 | 0.014776 | 0.014931 |
| 30 | 0.014698 | **0.014886** |

Best at the last epoch and still falling (−4.5e-5 over the last five), against 0.015413 for the
converged 36M-row run. The train/val gap is 0.00019 at epoch 30 versus 0.00056 for the 36M run
at the same epoch: more data closed most of it. Full curve in `h256-52m-history.json`.

Sanity table after epoch 30 (White to move):

```
start +46cp  |  +1 pawn (white) +132cp  |  +1 rook (white) +505cp  |  mate in 1 (white) +1047cp
```

The start position drifting to +46 and the pawn to +132 is worth noting against v1's +23/+70;
the lichess labels have a +155 cp mean, so a slight optimism for the side to move is what the
data says, and the rook sits on +505 either way.

## Commands

```bash
cat chunks/c0[0-9].part chunks/c[1-3][0-9].part > data/nnue/lichess_prefix.zst   # 7.5 GB
uv run python -m tools.nnue.data lichess --input data/nnue/lichess_prefix.zst \
  --positions 90000000 --out tools/nnue/data/lichess-48m --mirror
uv run python -m tools.nnue.train --data tools/nnue/data/lichess-48m --epochs 30 --hidden 256 \
  --checkpoints tools/nnue/checkpoints-h256-90m
uv run python -m tools.nnue.export --checkpoint tools/nnue/checkpoints-h256-90m/epoch_030.pt \
  --out weights/nnue-h256-52m.npz --qa 256 --qb 1024
uv run python -m tools.nnue.test_export --weights weights/nnue-h256-52m.npz \
  --checkpoint tools/nnue/checkpoints-h256-90m/epoch_030.pt
```

(The shard directory is named `lichess-48m` from the estimate made before the count was known.)
