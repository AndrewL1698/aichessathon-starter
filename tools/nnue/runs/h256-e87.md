# nnue h256-e87 — `weights/nnue-h256-e87.npz`

The [h256](h256.md) configuration run to convergence: same 36M rows, same split and seed, 100
epochs instead of 30. Pipeline commit c800a07 (adds `--qb` to export).

## Training

`768 → 256 → 32 → 1`, Adam lr 1e-3 with no schedule, batch 16384. 7.4 s/epoch, 12.3 min.

| epoch | train | val |
|---|---|---|
| 10 | 0.015648 | 0.015951 |
| 30 | 0.014999 | 0.015563 |
| 50 | 0.014816 | 0.015510 |
| 68 | 0.014717 | 0.015443 |
| 87 | 0.014658 | **0.015413** |
| 100 | 0.014628 | 0.015429 |

**Where it stops improving:** the last validation drop of at least 1e-5 over the running best
is at epoch 68; from there to 100 the curve moves within ±2e-5 while train keeps falling, so
the train/val gap opens from 0.00056 at epoch 30 to 0.00080 at epoch 100. More epochs on this
data buy nothing; more data would. Best checkpoint epoch 87 (0.015413 vs 0.015613 for h256 at
epoch 29 and 0.016537 for v1). Full curve in `h256-e87-history.json`.

## Export

The longer run grows the layer-1 weights further: at qa=512 the 32-men bound reaches 43986
(fails). Exported at **qa=256, qb=1024** (qc=128, cp_scale=400): headroom 10,773; 275,732 bytes.
At qa=256 with the default qb=512 the worst-case error was 25.40 cp, 0.4 cp over the gate;
qb=1024 keeps the layer-2 product on the same qa*qb scale as 512x512.

- `test_export`: **2.80 cp mean, 11.17 cp p99, 24.27 cp max** (tolerance 5 / 25); re-encode
  exact 1000/1000; mirror invariance 1000/1000. OK. The worst case is close to the gate.

For the record, re-exporting the epoch-29 h256 file at qb=1024 made its mean *worse*
(5.28 cp vs 5.00), so the committed `nnue-h256.npz` stays at qa=512, qb=512. The test is seeded,
so that is a real difference, not sampling noise.

## Commands

```bash
uv run python -m tools.nnue.train --data tools/nnue/data/lichess --epochs 100 --hidden 256 \
  --checkpoints tools/nnue/checkpoints-h256-long

  --out weights/nnue-h256-e87.npz --qa 256 --qb 1024
uv run python -m tools.nnue.test_export --weights weights/nnue-h256-e87.npz \
  --checkpoint tools/nnue/checkpoints-h256-long/epoch_087.pt
```
