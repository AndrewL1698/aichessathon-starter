# nnue h256 — `weights/nnue-h256.npz`

Same data, same pipeline commit and same machine as [v1](v1.md); only the hidden size changed.

## Training

`768 → 256 → 32 → 1`, clipped ReLU, MSE on `sigmoid(cp/400)`, Adam lr 1e-3, batch 16384,
30 epochs, same 2% split and seed as v1. **7.4 s per epoch**, 3.7 min total.

| epoch | train | val |
|---|---|---|
| 1 | 0.021130 | 0.018701 |
| 10 | 0.015788 | 0.016088 |
| 20 | 0.015308 | 0.015769 |
| 29 | 0.015083 | **0.015613** |
| 30 | 0.015069 | 0.015624 |

Best validation 0.015613 at epoch 29 against v1's 0.016537 (mean predictor 0.065778). The
exported checkpoint is epoch 29. The full curve is in `h256-history.json`.

Sanity table after epoch 30 (the printed one; epoch 29's is in the log within a few cp):

```
start +28cp  |  +1 pawn (white) +94cp  |  +1 rook (white) +556cp  |  mate in 1 (white) +1682cp
```

## Export

`epoch_029.pt` at **qa=512** (qb=512, qc=128, cp_scale=400), for the same reason as v1.

- headroom 10,379 of 32,767
- 290,804 bytes on disk
- `test_export`: int vs float **5.00 cp mean, 11.70 cp p99, 18.62 cp max** (tolerance 5 / 25,
  so the mean sits right on the limit: twice the hidden units means twice the layer-2
  rounding terms); re-encode exact 1000/1000; mirror invariance 1000/1000. OK.

## Commands

```bash
uv run python -m tools.nnue.train --data tools/nnue/data/lichess --epochs 30 --hidden 256 \
  --checkpoints tools/nnue/checkpoints-h256
uv run python -m tools.nnue.export --checkpoint tools/nnue/checkpoints-h256/epoch_029.pt \
  --out weights/nnue-h256.npz --qa 512
uv run python -m tools.nnue.test_export --weights weights/nnue-h256.npz \
  --checkpoint tools/nnue/checkpoints-h256/epoch_029.pt
```
