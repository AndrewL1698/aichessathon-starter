# nnue h512-52m-res — `weights/nnue-h512-52m-res.npz` (residual)

[h256-52m-res](h256-52m-res.md) at twice the width. Same 90M rows with the `hand` array, same
formulation (`eval = hand + raw × 400`, `target = "residual"` in the npz), hand evaluation from
origin/prod 8b0d4d0. Pipeline commit 5e4e9a6.

## Two runs, one file

| clip | val at 60 | export | int vs float |
|---|---|---|---|
| `--l1-clip 3.8` | 0.013544 | qa=256: **fails** the 25 cp gate (max 31.3 at qb=1024, 30.3 at qb=2048) | — |
| `--l1-clip 1.9` | **0.013495** | qa=512 qb=1024, headroom 1,187 | **2.95 mean / 6.54 p99 / 14.57 max** |

The first run's failure was diagnosed by quantising one layer at a time on the same 1000
positions: layer-1 rounding at qa=256 alone gave a 27.1 cp worst case, layer 2 alone 6.1,
layer 3 alone 5.3; the same weights at qa=512 would have been 9.3. qa=512 needs the layer-1
clip at 1.9 (bound 33 × 1.9 × 512 = 32,102), and the clip at 3.8 was binding (|w1| max 3.80), so
it was a retrain. **The tighter clip cost nothing**: val 0.013495 against 0.013544, inside noise
but not worse. The shipped file is the clip-1.9 run. 512 hidden units double the rounding terms
of every layer over H=256, which is why the H=256 residual passed at qa=256 and this did not.

## Training (clip 1.9)

`768 → 512 → 32 → 1`, Adam lr 1e-3, batch 16384, 60 epochs, `--l1-clip 1.9`. 28.5 s/epoch
(37.6 s for the last ten, the machine was shared), 31 min.

| epoch | train | val |
|---|---|---|
| 1 | 0.017310 | 0.015662 |
| 10 | 0.013636 | 0.013932 |
| 20 | 0.013292 | 0.013692 |
| 30 | 0.013133 | 0.013603 |
| 40 | 0.013041 | 0.013567 |
| 50 | 0.012984 | 0.013512 |
| 60 | 0.012946 | **0.013495** |

Baselines on the same split: mean predictor 0.055503, hand evaluation alone 0.032934, H=256
residual 0.014504. Width still pays: −0.0010 for 2× hidden, about ten times the run-to-run
noise. Still falling at ~1.7e-5 per epoch. Full curve in `h512-52m-res-history.json`.


## Export

qa=512, qb=1024, qc=128, cp_scale=400, target=residual: headroom 1,187 of 32,767 (the clip
guarantees it; 1.9 is the largest clip that fits qa=512); **608,975 bytes**, 1.2% of the zip
cap. Runtime cost: twice the accumulator width of H=256, which the engine session should bench
before choosing it.

- `test_export`: 2.95 cp mean, 6.54 cp p99, 14.57 cp max (tolerance 5 / 25); re-encode exact
  1000/1000; mirror invariance 1000/1000. OK.

## Commands

```bash
uv run python -m tools.nnue.train --data tools/nnue/data/lichess-48m-hand --target residual \
  --epochs 60 --hidden 512 --l1-clip 1.9 --checkpoints tools/nnue/checkpoints-h512-res-c19
uv run python -m tools.nnue.export --checkpoint tools/nnue/checkpoints-h512-res-c19/epoch_060.pt \
  --out weights/nnue-h512-52m-res.npz --qa 512 --qb 1024
uv run python -m tools.nnue.test_export --weights weights/nnue-h512-52m-res.npz \
  --checkpoint tools/nnue/checkpoints-h512-res-c19/epoch_060.pt
```
