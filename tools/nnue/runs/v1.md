# nnue v1 — `weights/nnue.npz`

Trained 2026-09-08 on the M5 Max (48 GB, torch 2.13.0, MPS) from `nnue/pipeline` at 3b8bc63.
The weight file in this branch is the only artefact; data, shards and checkpoints stayed local.

## Data

- **Source:** the lichess evaluations database (path A, no Stockfish on this machine),
  https://database.lichess.org/lichess_db_eval.jsonl.zst, 21,681,515,630 bytes on 2026-09-08,
  last-modified 2026-08-02. Only the first 3,187,500,000 bytes were read.
- **Ingest:** 23,054,909 records read, 2,131,311 skipped (no usable score, in check, or not a
  valid position: the file holds analysis-board setups with eight queens a side), leaving
  **20,923,598 unique positions** plus **15,076,402 a-h mirrors** (`--mirror`; castling
  positions are not mirrored) = **36,000,000 rows** in 72 shards, 559 MB. Sign check
  +0.512 white to move / +0.407 black to move.
- **Label distribution** (first 1.5M rows): mean +155 cp, std 929 cp, 20.3% of rows sit at
  the ±2000 clip. This database is heavy on decisive positions.

## Training

`768 → 128 → 32 → 1`, clipped ReLU, MSE on `sigmoid(cp/400)`, Adam lr 1e-3, batch 16384,
30 epochs, 2% validation split (720,000 rows), seed 1. **5.9 s per epoch**, 3.0 min total.

| epoch | train | val |
|---|---|---|
| 1 | 0.021857 | 0.019276 |
| 5 | 0.017554 | 0.017530 |
| 10 | 0.016950 | 0.017068 |
| 20 | 0.016578 | 0.016765 |
| 30 | 0.016334 | **0.016537** |

Predicting the mean target scores 0.065778 on the same split, so the net removes 75% of the
variance. Validation was still falling by ~2e-5 per epoch at epoch 30; the full curve is in
`v1-history.json`.

Sanity table after epoch 30 (raw centipawns, White to move):

```
start +23cp  |  +1 pawn (white) +70cp  |  +1 rook (white) +507cp  |  mate in 1 (white) +854cp
```

## Export

`epoch_030.pt` exported at **qa=512** (qb=512, qc=128, cp_scale=400). At the default qa=1024
the int16 proof failed: the 32-men worst-case bound reached 45217 against 32767, because the
unconstrained layer-1 weights go up to 2.43. The real accumulator over 500,000 data rows peaks
at 7552, so the model itself is fine; halving qa halves the bound. The runtime reads `qa`
from the file.

- headroom 10,155 of 32,767 (worst hidden neuron, 32 men)
- 144,961 bytes on disk
- `test_export`: int vs float over 1000 positions **2.02 cp mean, 8.76 cp p99, 12.62 cp max**
  (tolerance 5 / 25); re-encode exact 1000/1000; mirror invariance 1000/1000. OK.

## Commands, exactly as run

```bash
# download: lichess returns 429 above ~6 concurrent range requests and caps a single
# connection at ~0.4 MB/s, so 24 chunks were fetched 6 at a time with curl -sf and
# concatenated in order; only chunks 0-16 (3.19 GB) were needed.
cat chunks/c0[0-9].part chunks/c1[0-6].part > data/nnue/lichess_prefix.zst

uv run python -m tools.nnue.data lichess \
  --input data/nnue/lichess_prefix.zst --positions 36000000 \
  --out tools/nnue/data/lichess --mirror
uv run python -m tools.nnue.train --data tools/nnue/data/lichess --epochs 30 --hidden 128
uv run python -m tools.nnue.export --checkpoint tools/nnue/checkpoints/epoch_030.pt \
  --out weights/nnue.npz --qa 512
uv run python -m tools.nnue.test_export --weights weights/nnue.npz \
  --checkpoint tools/nnue/checkpoints/epoch_030.pt
```
